# Fonts

Self-hosted Latin subsets, downloaded from Google Fonts:

- **Geist** and **Geist Mono** — by Vercel, SIL Open Font License 1.1 (https://github.com/vercel/geist-font)
- **Instrument Serif** — by Instrument, SIL Open Font License 1.1 (https://github.com/Instrument/instrument-serif)

The OFL allows free use, embedding and self-hosting on websites.
