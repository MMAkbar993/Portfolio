01Overview

GreenUniMind — "Learn Green. Live Better." — is an online learning platform for sustainability and environmental education. Learners browse course categories, enrol in free and paid courses, learn through video lessons, track their progress and earn certifications they can share with employers.

Instructors publish their own courses, with AI features that help them write and improve course content.

02The problem

A modern learning product needs much more than pages of content: reliable video that plays well on any connection, secure payments, useful AI features and dashboards that show progress. Each of those is its own engineering problem, and they all have to work together.

03The solution

A React and TypeScript frontend backed by a Node.js API, with specialised services for each hard problem: FFmpeg and Mux for video processing and HLS streaming, Cloudinary for media, Stripe for payments and Google Gemini for AI features — all deployed on VPS infrastructure.

04My contribution

I built the platform end to end — frontend, backend, media pipeline and deployment — including:

  • Frontend in React and TypeScript, with Redux and React Query for application state and data fetching.
  • AI features using Google Generative AI (Gemini).
  • Video pipeline with FFmpeg, Mux and HLS streaming.
  • Payments with Stripe and media with Cloudinary.
  • Dashboards with charts and PDF generation.
  • Deployment on VPS infrastructure.

05Key features

Course marketplace

Categories, beginner and advanced levels, free and paid courses, a cart and enrolment.

AI Enhance for instructors

AI built on Google Gemini that automatically improves a course's description.

Certifications

Certificates learners can share on LinkedIn, on resumes and with employers.

Progress tracking

Progress indicators that show each learner how far they've come.

Video streaming

Uploaded video processed with FFmpeg and streamed as HLS via Mux.

Payments

Checkout and payments handled with Stripe.

Dashboards & PDFs

User-facing dashboards with charts, and PDF generation from platform data.

09Engineering decisions

  • Adaptive streaming. Video is processed into HLS so playback adapts to each learner's connection.
  • Managed services for hard problems. Stripe, Mux and Cloudinary handle payments, streaming and media, so product work stays focused on learning features.
  • Clear state management. Redux for application state and React Query for server data and caching.
